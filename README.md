# FOT-IULS
Intelligent University Library System 

Our project, Intelligent University Library & Research Platform, is a modern web based system designed to improve the way students, staff, researchers, and librarians use university library services. The platform brings together book searching, borrowing, reservations, digital reading, research publication, academic discussions, and personalized recommendations in one place. It also includes intelligent search and AI supported features to help users find and understand academic resources more easily. The system is designed to be secure, user friendly, responsive, and scalable, while ensuring that normal library services can continue even if AI features are unavailable.
